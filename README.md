- **Remote build platform**: architected and built Pantacor's builder service, distributed runners, API and MCP tools (Go, MongoDB, Docker BuildKit) that turn a container image or Git repository (Dockerfile, Yocto, Buildroot) into signed, multi-arch device packages and flashable images.
- **AI workflow automation**: the Pantacor Hub MCP server (34 tools) with its own OAuth 2.1 authorization server, and the pantavisor-apps Agent Skill that lets AI assistants build and deploy device apps with human approval.
- **Pantacor Fleet**: the release and fleet-management platform one customer runs 15,000+ Linux devices on (Go/React): phased rollouts, rule-based channels, multi-tenant authorization (SpiceDB, OPA).
- **Security architecture**: passkeys and 2FA, OAuth 2.1 / OIDC / PKCE and SSO, TLS device onboarding, certificate revocation, device secret rotation.
- **[forEach developer](https://foreachdeveloper.com/)**: my open-source studio of apps that run on your own machine, AI included: Oriel, GhostPen, GhostReel and HollerShare.
